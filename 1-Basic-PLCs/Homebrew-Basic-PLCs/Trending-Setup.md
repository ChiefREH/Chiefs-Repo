# TRENDING SETUP

Using the "Heartbeat Timer" routine, **trend** the operation of the **.DN** bit:
- Set **PENS** to a color easily viewed (I use yellow or orange)
- Set **Y-AXIS** to **Custom**
    - Min Value = -1
    - Max Value = +2

_This configuration puts the trace (either 0 or 1) right in the middle of the chart._
