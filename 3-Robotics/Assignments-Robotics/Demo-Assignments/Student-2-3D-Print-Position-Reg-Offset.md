# 3D PRINTER WITH POSITION REGISTER OFFSETS

STUDENT ASSIGNMENT

- Must offset the X, Y and Z coordinates.
- Include logic to prevent exceeding motion limits for any axis.


## OFFSET DIRECTIONS
```
FIRST:  -X, +Z
SECOND: -Y, +Z
THIRD:  +X, +Z
FOURTH: +Y, +Z
```

## OFFSET PARAMETERS
- **10 loops** for each direction
- **+5 mm** / layer SOFT-CODED in a Register R[ ]
