# MECHSIMULATOR ASSIGNMENT 3 - ECRC SGNALS

Using ELECTRICAL CONTROLS, create the following simulation:

- Extend the Cylinder / Red light ON
- Center the Directional Control Valve
- Retract the Cylinder / Green light ON
- Center the Directional Control Valve
- Repeat

## PARAMETERS

- Toggle Switch is acceptable
- Can use a Seal-In circuit, but not required
- Lights can be ON or OFF when the DCV is centered
