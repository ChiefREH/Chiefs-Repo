# Cylinder Speed

## Formula
`V = Q ÷ A`

## Variables
- V = Velocity
- Q = Flow Rate
- A = Area

## What It Means
Cylinder speed depends on how much fluid enters the cylinder and how large the piston area is.

## Example
If pump flow doubles, cylinder speed doubles. If piston area doubles, cylinder speed is cut in half.

## Key Concept
Higher flow increases speed; larger cylinders move slower at the same flow rate.
